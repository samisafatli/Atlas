# Atlas

Aplicativo financeiro pessoal local-first. O projeto está sendo construído em
pequenas etapas; por enquanto, esta é apenas a fundação da aplicação.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Começar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Comandos úteis

```bash
npm run lint
npm run typecheck
npm run format
npm run build
```

## Tecnologias

- Next.js com App Router
- TypeScript
- Tailwind CSS
- ESLint e Prettier

## Estrutura

```text
src/
  app/        Rotas, layout e estilos globais
```

O Atlas não usa autenticação nem serviços externos nesta etapa.
